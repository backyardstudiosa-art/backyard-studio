FOODLIFE with Karé — landing page files

Folder contents:
- index.html — homepage
- style.css — shared stylesheet for the homepage and recipe
- recipes/lemon-spinach-pasta.html — recipe page using ../style.css

To install in GitHub:
1. Replace studio/foodlife/index.html with this index.html.
2. Create/update studio/foodlife/style.css with this style.css.
3. Replace studio/foodlife/recipes/lemon-spinach-pasta.html with the supplied recipe file.
4. Commit the changes, then test the homepage and recipe link.

The logo is currently a text wordmark, so no logo asset is needed yet. Food photographs use remote Unsplash URLs as placeholders and can later be replaced with local images in assets/.
